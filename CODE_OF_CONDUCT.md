# Code of Conduct

## Our Standard

Participation in this project should remain respectful, direct, and technically constructive.

Examples of expected behavior:

- critique code and decisions, not people
- keep bug reports and reviews factual
- provide reproducible technical context when raising concerns
- respect maintainer time by keeping requests scoped and actionable

Examples of unacceptable behavior:

- harassment or personal attacks
- hostile or discriminatory language
- intentionally misleading technical claims
- spam, abuse, or bad-faith issue filing

## Enforcement

Project maintainers may remove comments, close threads, or block participation when behavior violates these standards.
